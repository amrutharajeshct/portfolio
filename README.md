## 🚀 Live Demo & Local Preview

This project runs directly in the browser with **zero external runtime dependencies or build steps** required.

### Method 1: Direct File Opening
Navigate to `C:\Users\pmcuser3\.gemini\antigravity\scratch\mysql-developer-portfolio` in Windows File Explorer and double-click `index.html`.

### Method 2: Python Local Server
Open PowerShell in the project directory:
```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000`

### Method 3: Node.js / npx serve
```bash
npx serve .
```
Then visit: `http://localhost:3000`

### Method 4: VS Code Live Server
1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Click **"Go Live"** in the bottom status bar.
